Manual/Getting started

FIRST-TIME SETUP

From a Heltec board to your Kitsu.

You need a supported Heltec WiFi LoRa 32 V3, a USB data cable, an Android phone running Android 8 or newer, and about fifteen minutes.

1. Install the firmware

  1. Connect the Heltec with a USB data cable.

    A charge-only cable will power the board but cannot install firmware.

  2. Open the Kitsu firmware installer in a Web Serial browser.

    Use a current Chromium-based desktop browser. Mobile browsers and Firefox do not provide the required serial interface.

  3. Select Install and choose the Heltec serial port.

    The installer checks the board type, flash size, signed release, and exact image hashes before writing.

  4. Wait for write and read-back verification.

    Do not unplug the board. A successful install ends with a verified restart into Kitsu.

Do not choose a full-chip erase.The Kitsu installer performs targeted writes and preserves the bootloader, companion pack, saved state, and connectivity data. Follow the recovery guide before using any unrelated flashing tool.

2. Install Android

  1. Download the current signed Android APK.

    Use the Android download on the Kitsu product page, then allow installation from your browser when Android asks.

  2. Allow installation from your browser.

    Android may ask you to allow this source. That permission can be turned off again immediately after installation.

  3. Open Kitsu and grant nearby-device access.

    Android 12 and newer ask for Nearby devices. Android 8–11 may ask for Location because those versions tie Bluetooth scanning to that permission.

3. Put Kitsu in phone-pairing mode

  1. From Home, hold PRG for at least 750 ms.

    The main menu opens.

  2. Hold PRG while CONNECT is selected.

    The connection menu opens. If it starts on WIFI, short-press until BLUETOOTH appears.

  3. Hold PRG on BLUETOOTH.

    Kitsu opens the time-limited PAIR PHONE window.

  4. In Android, open More and scroll to Pair this phone.

    Enter a phone label and tap Pair nearby Kitsu.

4. Compare the code and grant the phone

  1. Compare Android's six digits with Kitsu's MATCH CODE screen.

    If they differ, cancel both sides and start again. Never approve a mismatch.

  2. Accept Android's pairing prompt.

    When Kitsu asks for confirmation and the codes match, hold PRG.

  3. Wait for the second physical prompt.

    The app shows that it is waiting for PRG; Kitsu shows PHONE READY.

  4. Hold PRG again to grant this phone.

    The device creates a controller credential for that installation of the app.

There are two PRG holds during phone setup.The first confirms the Bluetooth numeric comparison. The second grants the authenticated Kitsu controller. Both are intentional.

5. Confirm nearby control

  • The app should show Direct Bluetooth and current companion status.
  • Try Pet or Feed and confirm Kitsu reacts.
  • Open Messages and refresh the inbox.
  • Tap Disconnect when finished. This closes Kitsu's connection but does not turn off the phone's Bluetooth radio.

6. Optional: connect to the public gateway

  1. In More, tap Connect to public gateway.

    The phone creates an encrypted relay credential for this installation. No owner account is required.

  2. Watch Kitsu for GATEWAY / HOLD PRG / TO ENROLL.

    Hold PRG once before the countdown expires.

  3. Wait for Connected to public gateway.

    The phone now carries Kitsu's authenticated traffic over its own Internet connection. The Heltec does not need Wi-Fi.
