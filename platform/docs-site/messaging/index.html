Manual/Messaging

MESHCORE MESSAGES

Talk to a peer or a channel.

Kitsu supports direct messages to a complete MeshCore public key and channel messages on configured channel slots 0 through 3. Message text is limited to 128 UTF-8 bytes.

Before sending

  • MeshCore must be enabled with a valid radio profile.
  • The destination peer or channel must be present in Kitsu's current data.
  • A direct recipient uses the complete public-key reference; shortened display IDs are not valid destinations.
  • A channel must be configured on the device before it can be selected.
  • Transmission remains subject to the regional duty-cycle and explicit transmit policy.

Send a direct message

  1. Connect Kitsu, then open Messages.

    The app loads device-reported messages, peers, and channels when it refreshes the active Bluetooth session.

  2. Tap Direct, then use Choose a nearby peer.

    Each discovered client peer appears by name with a compact key reference. Tapping it writes that peer's exact full 43-character key into Peer key; manual full-key entry remains available.

  3. Write up to 128 UTF-8 bytes.

    Emoji and non-ASCII characters may use more than one byte, so the character count can be below 128.

  4. Tap Send over mesh once.

    The app assigns an idempotency identifier so a retry cannot create a second accepted action with the same request.

Send a channel message

  1. Tap Channel instead of Direct.

    The target field changes from Peer key to Channel 0–3 and an incompatible previous target is cleared.

  2. Choose a channel.

    Configured channels appear by name and slot, such as Public · slot 0. Tapping one writes its digit into Channel 0–3; manual slot entry remains available.

  3. Compose and tap Send over mesh.

    Anyone with the matching MeshCore channel configuration may receive the message.

What the app shows

Messages lists the current device-reported history with message text and peer or channel context. Authenticated Bluetooth refresh events update that bounded list while Kitsu is connected. You can also tap Refresh in the Connection card to request the current state, peers, channels, and complete 24-message device ring; the app does not invent a separate delivery panel.

Read messages on Kitsu

Open INBOX from the device menu. A short press moves to the next older message. Hold PRG to return Home. The Android app provides a longer scrollable device-reported history.

Mesh messages are not private chat by default.Radio participants with the relevant keys or channel configuration may receive them. Do not send passwords, private keys, Wi-Fi credentials, or information that must remain confidential.

If sending fails

  • Reconnect so the app reloads peers and channels.
  • Confirm the intended channel is configured.
  • Turn on Local mesh radio in the Mesh tab.
  • Use a shorter message if the text contains multi-byte characters.
  • Wait for the current radio duty-cycle window.
  • Review Troubleshooting with the exact error shown by the app.
