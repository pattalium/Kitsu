KITSU USER MANUAL

Everything you need to use Kitsu.

Kitsu is a local-first portrait companion running on a Heltec WiFi LoRa 32 V3. This manual covers the first firmware install, Android pairing, one-button device controls, care, messages, authenticated Bluetooth, signed A/B updates, and recovery.

What Kitsu does

Companion

Care, needs, and memory

Pet, feed, play, listen, sleep, build affection, and create memories from nearby radio activity.

Device

Portrait OLED interface

Home, menu, inbox, games, listening, sleep, info, and phone setup are designed for the 64 × 128 display.

Phone

Native Android control

Authenticated Bluetooth carries state, history, care, messaging, radio configuration, explicit Disconnect, and signed offline updates.

Radio

MeshCore network client

Kitsu can receive ordinary MeshCore traffic and send approved direct or channel messages under the configured radio policy.

The shortest successful setup

  1. Install the current firmware.

    Use the browser installer with a supported Heltec board and a USB data cable.

  2. Install Kitsu for Android.

    Download and install the signed Android APK from the product page, then allow installation from the browser when Android asks.

  3. Open Bluetooth pairing on Kitsu.

    From Home, hold PRG for the menu, leave CONNECT selected and hold, leave BLUETOOTH selected and hold again.

  4. Compare the six-digit number.

    Accept Android's pairing prompt only when its number matches Kitsu. Hold PRG on Kitsu when instructed.

  5. Grant the phone.

    When the app waits for PRG and Kitsu shows PHONE READY, hold PRG a second time.

  6. Use Kitsu nearby.

    Bluetooth is the complete supported control path. No account, Wi-Fi, gateway, or Internet connection is required.

About the PRG buttonA short press is less than 750 ms. A hold is 750 ms or longer. PRG is also the board's boot button, so do not hold it while resetting unless you intentionally want firmware-download mode.
