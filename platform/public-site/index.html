THE COMPANION LIVES HERE

More than a screen on a radio.

Care changes Kitsu over time. Encounters become memories. Messages arrive in an inbox. Games, sleep, mood, and progression continue on the Heltec itself.

01

Care and personality

Pet, feed, play, listen, sleep, and watch needs and affection develop through normal use.

02

Games on-device

Play Signal Catch and Pounce with the single PRG button, directly on the portrait OLED.

03

Messages that travel

Send direct peer messages or talk on one of four MeshCore channels from the Android app.

04

Memory and encounters

Kitsu records meaningful sightings and radio activity instead of behaving like a disposable display.

CONNECTED WHEN IT HELPS

Three paths. One companion.

01

Bluetooth nearby

Pair securely, care for Kitsu, read history, send messages, configure Wi-Fi, and disconnect when you are finished.

02

Public gateway through Android

Keep Kitsu portable: the paired phone carries its encrypted gateway traffic over any working Internet connection. Kitsu itself needs no Wi-Fi or owner account.

03

MeshCore over LoRa

Kitsu receives standard MeshCore traffic and uses the configured regional radio profile for approved transmissions.

FROM BOARD TO COMPANION

Set up once. Keep using it your way.

  1. 1
    Install Kitsu firmware

    Use the browser flasher with a supported Heltec board. The installer preserves companion data and writes only the reviewed firmware regions.

  2. 2
    Install the Android app

    Download and manually install the signed Android APK below. Android 8 or newer is required.

  3. 3
    Pair with physical confirmation

    Compare the six-digit code on Android and Kitsu, accept only if they match, then follow the two PRG prompts.

  4. 4
    Connect to the public gateway

    Tap the button in Android and hold PRG when Kitsu asks. No username, password, or Heltec Wi-Fi setup is required.

YOUR HARDWARE STAYS YOURS

Reflashable by design.

Kitsu does not permanently lock the Heltec. You can update it, erase it, return to stock MeshCore, or repurpose the board. Network connections still use authenticated Bluetooth, pinned TLS, scoped gateway credentials, signed actions, and replay protection.
