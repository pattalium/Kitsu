FROM BOARD TO COMPANION

Set up once. Keep using it your way.

  1. 1
    Install an accepted Kitsu firmware release

    The browser flasher stays unavailable until a physically accepted release passes its signature and byte checks. When available, it writes only the reviewed rollback bootloader, partition table, both A/B application slots, both clean private update journals, and an exact clear over the isolated legacy connectivity partition while preserving companion data.

  2. 2
    Install the Android app

    Use the download below only when its verified local-first release link is enabled, then manually install the signed APK. Android 8 or newer is required.

  3. 3
    Pair with physical confirmation

    Compare the six-digit code on Android and Kitsu, accept only if they match, then follow the two PRG prompts.

  4. 4
    Use Kitsu locally

    Connect to a saved Kitsu over Bluetooth. Care, history, messages, radio settings, and firmware updates work without an account, gateway, Wi-Fi, or Internet connection.

YOUR HARDWARE STAYS YOURS

Reflashable by design.

Kitsu does not permanently lock the Heltec. You can update it over signed Bluetooth OTA, recover it over USB, erase it, return to stock MeshCore, or repurpose the board. Nearby commands use authenticated Bluetooth with per-session keys, sequence checks, and replay protection.
