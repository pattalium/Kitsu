Privacy and local data

Local-first operation

The Kitsu Android app does not require an account and does not have permission to access the Internet. It communicates with a nearby Kitsu only through an authenticated Bluetooth session. Care actions, companion state, messages, peers, channels, saved Kitsu authorizations, cached history, and imported firmware packages remain on the phone or Heltec unless you independently transmit a MeshCore radio message.

Data on Android

The app stores controller credentials in Android Keystore-backed encrypted storage. Its bounded encrypted cache can contain the selected Kitsu's state, history, peers, and messages. A firmware image chosen through Android's document picker is copied temporarily into the app-private cache for verification and transfer. The app does not upload analytics, device state, location, contact data, or diagnostics. Forget authorization removes the selected controller credential after device revocation is confirmed; Android may retain its separate system Bluetooth bond.

Data on the Heltec

The device stores companion state, installed visual packs, MeshCore configuration and journals, and granted Bluetooth controller records in its own flash. Signed Bluetooth firmware updates write only the inactive application slot and the boot-selection metadata needed for A/B activation; they do not erase companion data, packs, controller records, or MeshCore state. The local-only transition separately erases and verifies the isolated partition that held old Wi-Fi and gateway credentials and removes only the retired LAN-action namespace.

Website and support

The public website distributes signed release files and documentation. Ordinary web hosting logs may contain request metadata such as network address, user agent, requested path, and timestamp. If you choose to use GitHub for source, bug reports, or private vulnerability reporting, GitHub processes that interaction under its own terms and privacy notice. Following the Ko-fi support link transfers your visit to Ko-fi; any payment interaction then takes place on Ko-fi under its own terms and privacy notice. Kitsu's static site does not embed payment code or collect payment details. Kitsu does not operate a product account or contact-form database.

Historical service records

Records created by retired pre-local-first account and gateway releases may be retained offline for security, audit, and rollback purposes. They are not used by the local-first app or firmware and are not recreated by normal Bluetooth use.

Questions

Use the static support page for the public project links. Never publish controller secrets, private keys, complete flash dumps, or private radio traffic.
