Project questions and changes

Read the public source repository and its existing issue archive first. New public issues are currently restricted, so this page does not pretend that archive is a working submission form. A concrete source or documentation fix can be proposed through a pull request.

Security vulnerabilities

Use private vulnerability reporting for a security issue that should not be public before a fix exists.

What not to post

Never submit controller credentials, private keys, complete flash dumps, pairing secrets, or third-party radio traffic. Kitsu has no product account, support-login database, or server-side device record in its local-first release.
