Device

Write and read back

Install unlocks only for an ESP32-S3 with 8 MiB flash. It performs seven verified core writes: the rollback-enabled Kitsu bootloader, partition table, the same accepted app in app0 and app1, a clean private OTA journal in each slot, and one exact clear over the isolated retired connectivity partition. After those readbacks pass, it optionally writes the selected companion pack to its dedicated slot in the same USB session. One final reset boots the complete result.

Keep current pet selected. The companion-pack slot will not be written. Choose Fox, Cat, Dog, or a downloaded unlocked .k868 file for a new or packless Kitsu.

Owner-reflashable by design. This installer writes the reviewed Kitsu bootloader so Bluetooth updates can roll back safely and clears only the retired partition that held legacy Wi-Fi, gateway, and server credentials. It never calls full-chip erase and never writes OTA data, companion state, controller records, MeshCore state, coredump, or eFuses. The companion slot changes only when you explicitly choose Fox, Cat, Dog, or a locally validated unlocked .k868 file above. Ordinary serial recovery and restoration of stock MeshCore remain available.
